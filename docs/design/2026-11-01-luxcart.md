# LuxCart — OilStation visual authority (1 November 2026)

LuxCart replaces the former Gentelella v4 **visual** authority for all OilStation screens. It is a calm, high-end workspace interpretation of a luxury retail system: cream canvas, charcoal controls and copy, porcelain-white cards, hairline borders, and gold used only for micro-accents. **OilStation is still an operational petrol station application, not a fashion shop**; preserve Thai labels, operational density in tables, 44px action targets, real financial states, and role-specific workflows.

## Canonical tokens

- Primary charcoal `#1C1917`; hover `#292524`; active `#0C0A09`
- Cream background `#FFFBEB`; white surface `#FFFFFF`
- Gold micro-accent `#B8860B`; neutral divider `#D4D4D8`; hairlines `#E7E5E4`
- Semantic: success `#166534`, warning `#CA8A04`, error `#991B1B`, info `#1E40AF`
- Editorial Latin headlines: Cormorant Garamond (light/regular); Thai headline fallback: Noto Serif Thai
- Body: Raleway with Noto Sans Thai fallback. Monospace: JetBrains Mono
- 12px base with scale 4 / 8 / 12 / 24 / 36 / 48 / 72 / 96 / 144
- Square precision: controls 2px, cards 4px, large panels 6px, dialogs up to 8px
- Subtle shadows: `0 1px 2px rgba(28,25,23,.04)`, hover `0 2px 8px rgba(28,25,23,.06)`
- Desktop Home catalogue no more than three columns; no added marketing banners, fake KPIs or sale stickers

## Boundaries

`public/oilstation.css` is the **only** stylesheet loaded by `index.html`. After the 1 November cleanup, redundant legacy declarations and all 14 old CSS files were removed; edit the owning rule in this file rather than introducing another override layer. No data flow was changed. Only two navigation surfaces remain: on-screen functional submenus below the header (never on Home), and the five-position bottom frequent-destination dock; only Home shows the full authorized catalogue. Do not modify permission logic to style a page. Functional submenu selection must preserve mounted forms. Gold only decorates overlines, small marks and outlines, never large blocks. Status colors convey actual state.

All Thai transactional content remains legible with Noto Sans Thai system fallback. Web fonts are progressive enhancement; offline or blocked font loads must not break the interface. Honor keyboard focus, safe area insets, screen readers and reduced motion. When modifying CSS, prove login, Sales, authorized station, corporate and HR shell behavior with Chromium at desktop/mobile widths, in addition to the full Node regression suite.
